# Build pins

The tuple `(CHROMIUM_VERSION, DEPOT_TOOLS_REVISION, args/<target>.gn,
linux/Dockerfile, ../patches/series)` fully determines the output binary.
Changing any of them changes what ships, so each is a file rather than a
convention.

`CHROMIUM_VERSION` is `152.0.7977.82`. It is the current Linux stable and was
Mac stable immediately before `.83`, which is why it was chosen: under axiom A2
the browser must claim a version that genuinely exists in the wild for the
platform it presents, and this is the one version that is real on both.

`MANIFEST.lock` is generated by `scripts/build.sh` and records what a build
actually resolved, including output hashes. It is the artefact a rebuild is
compared against.
