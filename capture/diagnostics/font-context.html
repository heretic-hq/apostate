Help check this device's fonts

This optional check helps explain differences in text measurements. Nothing is measured or sent until you choose “Run and send font check.”

What you will share

  • Font names and style descriptions that this page can read, including accessible font-rule source addresses with credentials, query strings and fragments removed.
  • Text widths, character bounds and line spacing for a fixed set of sample text, plus the browser's reported version string, language and display scale.

No font files, browsing history, passwords or extension list are requested. The check does not ask for font-access permission or download fonts.

The result goes only to this page's operator as a separate diagnostic. It does not become a reference-device capture automatically.

Use a short nickname, without personal information.

Keep this tab open while the check runs. You can leave this page without running it.
